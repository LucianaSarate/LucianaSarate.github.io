## 🚀 Instalación y Uso

### Visualización Local

1. Clona el repositorio:
```bash
git clone https://github.com/LucianaSarate/LucianaSarate.github.io.git
```

2. Navega al directorio del proyecto:
```bash
cd LucianaSarate.github.io
```

3. Abre `index.html` en tu navegador preferido o usa un servidor local:
```bash
# Con Python
python -m http.server 8000

# Con Node.js (http-server)
npx http-server
```

### Publicación en GitHub Pages

El sitio se actualiza automáticamente al hacer push a la rama `main`:
```bash
git add .
git commit -m "Actualización del portafolio"
git push origin main
```

## 🎨 Personalización

### Colores Principales
```css
--primary-color: #2c3e50;     /* Azul oscuro profesional */
--secondary-color: #3498db;   /* Azul brillante */
--accent-color: #e74c3c;      /* Rojo de acento */
--text-primary: #2c3e50;      /* Texto principal */
--text-secondary: #7f8c8d;    /* Texto secundario */
```

### Modificar Contenido
- **Información personal:** Edita la sección `#about` en `index.html`
- **Experiencia laboral:** Modifica la sección `#experience`
- **Formación académica:** Actualiza la sección `#education`
- **Habilidades técnicas:** Personaliza la sección `#skills`
- **Intereses:** Ajusta la sección `#interests`
